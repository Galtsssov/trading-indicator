# Этап 3 — пререгистрация Information Ceiling Study

Документ закоммичен **до** написания и запуска кода измерения. После этого коммита правило решения,
метки, периоды и параметры (`configs/platform.toml`, секция `[ceiling]`) не меняются.

## Вопрос
Достаточно ли информации в текущем наборе данных — OHLCV, объём, taker buy/sell, OI, funding,
long/short, taker ratio, внутрибаровые минутные агрегаты и 339 признаков ядра Feature Factory — чтобы
для ETHUSDT и SOLUSDT на 5m и 15m получить RR ≥ 1:2 и win rate > 50 % после комиссий?

## Что измеряется
- **Сделка-метка** на каждом баре t и в каждом направлении (лонг, шорт): вход по открытию первой
  минуты после закрытия бара; стоп 1R, цель 2R; 1R = r_atr · ATR предыдущего бара; путь — минутные
  свечи (цель и стоп в одной минуте → стоп); выход по времени через 48 баров.
  Метка = 1, если цель достигнута раньше стопа. Результат сделки в R после издержек 0.14 % за круг
  (тейкер 0.05 % + проскальзывание 0.02 % за сторону).
- **Основная конфигурация:** r_atr = 2 (доля издержек в R вдвое меньше). Справочно — r_atr = 1.
- **Периоды:** training 2020-01-01 — 2023-12-31 (последние 20 % — для ранней остановки, с зазором в
  горизонт метки), validation 2024-01-01 — 2025-06-30. Holdout не открывается.
- **Признаки:** ядро Feature Factory (`reports/factory/core_features.json`, 339 признаков).
- **Основной прибор:** LightGBM. Остальные модели (XGBoost, CatBoost, Random Forest,
  HistGradientBoosting, MLP) — проверка, не упирается ли потолок в выбор модели.

## Правило решения (фиксировано)
Для основного прибора на validation, для каждой пары (монета × ТФ) и каждого k ∈ {1, 2, 3} лучших
сигналов в сутки (оба направления вместе, сигналы одного дня не ближе 12 баров) считаются:
- **WR** — доля сделок, где цель 2R достигнута раньше стопа;
- **EV** — средний результат в R после издержек;
- нижние границы доверительных интервалов — блочный бутстреп по дням, односторонний уровень
  0.05 / 12 (поправка Бонферрони на 2 монеты × 2 ТФ × 3 значения k).

**ДОСТАТОЧНО**, если хотя бы для одной пары монета × ТФ и одного k одновременно:
нижняя граница WR > 50 % **и** нижняя граница EV > 0 — и все проверки исправности пройдены.

**НЕДОСТАТОЧНО** — во всех остальных случаях. Тогда делается официальный вывод:
«В текущем информационном пространстве (OHLCV + производные + OI + Funding + Long/Short +
внутрибаровые признаки) достаточного сигнала для решения поставленной задачи не обнаружено».
Исследования в этом пространстве признаков завершаются. Не ищутся новые признаки из тех же данных,
не меняются параметры, следующий шаг — новые источники данных.

Отдельно (на решение не влияет) отчёт сообщает, **сколько** информации есть: AUC с доверительным
интервалом, максимум по всем моделям (оптимистичный потолок) и где эта информация сосредоточена.

## Проверки исправности (обязательны, иначе результат недействителен)
1. Перемешанные метки в training → AUC на validation в пределах 0.5 ± 0.01.
2. Встроенный эффект (метка искусственно зависит от добавленной случайной колонки) → прибор
   обнаруживает его: AUC растёт, колонка — первая по SHAP.
3. 20 случайных признаков → не попадают в топ-50 по SHAP и permutation importance.
