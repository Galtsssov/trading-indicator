# Торговый терминал ETH / SOL / BTC и исследовательская платформа

## Торговый терминал

**Рабочий инструмент на каждый день** — [docs/TERMINAL.md](docs/TERMINAL.md).
Объективная картина рынка (структура, ликвидность, VWAP, режим, позиционирование), статистика похожих
ситуаций из истории, журнал сделок со скриншотами и личная аналитика: что работает именно у вас.
Сигналов BUY/SELL нет — только факты и статистика.

Запуск: Windows — `start-terminal.bat`, macOS — `start-terminal.command`, или:

```bash
pip install -e ".[terminal]"
```

```bash
qlab-terminal
```

## Пять главных выводов этапа 1

1. **Издержки — первый фильтр, раньше любой идеи.** Ориентировочно: комиссия тейкера на перпах Binance
   около 0.04–0.05% за сторону. Круг «вход + выход по рынку» с проскальзыванием — около 0.1–0.12%.
   Типичный ATR 5m для ETH — порядка 0.25–0.4%, для SOL — 0.35–0.5% (оценка, проверить первым тестом).
   Значит, издержки съедают **0.25–0.4 ATR на сделку**. При стопе в 1 ATR это 25–40% риска на каждую сделку.
   Реальные статистические преимущества обычно составляют 0.03–0.1R. Вывод: на 5m с рыночными входами почти
   любой edge съедят издержки. Нужны 15m, далёкие цели (≥2–3 ATR), лимитные входы или торговля только
   в часы высокой волатильности.
2. **Почти все концепции SMC/ICT — это переименование трёх явлений:** краткосрочной реверсии
   после перекупленности/перепроданности, кластеризации волатильности и скопления стопов
   у очевидных уровней. Только третье имеет независимую научную основу (Osler, рынок FX).
   Поэтому каждое SMC-правило обязано **обыграть простую реверсию** с теми же параметрами
   (гипотеза К36). Если не обыгрывает — оно ничего не добавляет.
3. **Главная переменная — природа потока, а не геометрия графика.** Принудительный поток
   (стопы, ликвидации, закрытие позиций; на графике — падение OI) оставляет временный ценовой
   импакт, и цена откатывает. Добровольный, информированный поток (новые позиции, OI растёт,
   движение ведёт спот, двигается весь рынок вместе с BTC) оставляет постоянный импакт, и движение
   продолжается. Из этого выросла объединяющая гипотеза NIF (см. файл 03).
4. **Популярная идея «свип → разворот» противоречит самому сильному эмпирическому
   исследованию стопов (Osler: пробой скопления стопов → каскад → продолжение).**
   Без доказательств ставка на разворот в момент свипа — худший вариант. Если преимущество существует,
   его стоит искать **после** исчерпания каскада (цена вернулась за уровень, OI упал), а не на касании.
5. **Наиболее перспективны гипотезы, у которых есть механизм и измеримый «чужой» поток:**
   OI и ликвидации на свипе, межактивное подтверждение от BTC (SMT), спот против перпа,
   абсорбция, реверсия после каскада ликвидаций. Наименее перспективны те, что держатся только
   на геометрии: FVG, order block, уровни Фибоначчи (в т.ч. OTE 0.705), киллзоны, перенесённые с FX.

## Принципы

- Нулевая гипотеза для любой идеи: после издержек цена ведёт себя как мартингал.
- Контрольная выборка всегда подобрана по часу недели и режиму волатильности. Иначе «эффект» окажется
  обычной сезонностью волатильности.
- Плацебо-тесты: сдвинутые уровни, сдвинутые сессии, случайные точки входа.
- Считаем **каждую** протестированную вариацию и делаем поправку на множественные проверки.
- ETH и SOL коррелируют с BTC и друг с другом. Эффект на обеих монетах — не два независимых подтверждения.
- Ссылки на литературу даны по памяти исследователя. Перед тем как опираться на конкретную цифру, проверьте первоисточник.
