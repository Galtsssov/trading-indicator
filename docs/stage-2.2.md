# Этап 2.2 — платформа поиска edge

Главная гипотеза NIF закрыта (H001, Rejected). Этот этап строит систему, которая сама ищет
закономерности и сама отсекает ложные. Машинное обучение для прогноза цены не используется.

## Как пользоваться

```bash
pip install -e ".[dev]"
```

```bash
python -m qlab all
```

`all` = скачать данные → отчёт о качестве → кэш признаков → поиск аномалий на training →
проверка всех новых гипотез на validation. Holdout не трогается никогда.
На GitHub: Actions → research → Run workflow (результаты коммитятся сами).

Новая гипотеза — только YAML-файл в `hypotheses/` (образец — `H002-sweep-continuation.yaml`):

```bash
python -m qlab register hypotheses/H003-моя-идея.yaml
```

```bash
python -m qlab test H003
```

```bash
python -m qlab registry
```

Holdout — один раз, только после пройденной валидации и только осознанно:

```bash
python -m qlab test H003 --split holdout --confirm-holdout
```

## Что построено (по шагам задания)

| Шаг | Где | Как работает |
|---|---|---|
| 1. Разбивка истории | `configs/platform.toml [splits]`, `src/qlab/splits.py` | training 2020-01 — 2023-12, validation 2024-01 — 2025-06, holdout 2025-07 — … Holdout закрыт кодом: без разрешения реестра выбрасывается `HoldoutLocked`. Исход сделки не может «перетечь» в следующий период (события у границы отбрасываются) |
| 2. Hypothesis Registry | `hypotheses/registry.json`, `src/qlab/registry.py` | ID, название, источник, дата, статус (Testing / Rejected / Verified / Archived), причина, все проверки со ссылками на отчёты. **Отпечаток** — хэш смысла (событие, направление, фильтры, рынки, ТФ, исход): та же идея под другим именем не регистрируется. **Замок** — хэш всего YAML кроме названия и описания: после регистрации ничего менять нельзя. Holdout — один раз, только после validation |
| 3. YAML Engine | `src/qlab/hypothesis.py`, `src/qlab/expr.py`, `src/qlab/engine.py` | Гипотеза — событие + направление (with / against / long / short) + фильтры на безопасном языке условий (`oi_change < 0 and regime_vol == 'high_vol'`) + модель исхода + критерии. Ядро понимает это без правки кода |
| 4. Baseline Library | `src/qlab/baselines.py` | Каждая гипотеза автоматически сравнивается с: случайным входом (тот же час и дециль ATR), mean reversion, momentum, buy every sweep, sell every sweep. Не обыграла все — Rejected |
| 5. Event Library | `src/qlab/events/` | 13 типов: liquidity_sweep, breakout, compression, expansion, atr_expansion, vwap_touch, return_extreme, session_open (asia / london / ny с учётом летнего времени), range_break, news_window (NFP по правилу + календарь CSV), funding_spike, oi_spike, anomaly. Каждое — отдельный файл; новый файл подключается сам |
| 6. Гипотеза о продолжении | `hypotheses/H002-sweep-continuation.yaml` | Зарегистрирована и закоммичена **до** запуска (коммит 4be8a14): обоснование, признаки, подтверждение, опровержение, статистика, собственный прогноз. Отмечено загрязнение (см. ниже) |
| 7. Feature Cache | `src/qlab/cache.py`, `data/cache/` | Признаки считаются один раз на (монета, ТФ). Ключ — хэш содержимого данных + код признаков + параметры; изменилось что-то — пересчёт сам |
| 8. Regime Engine | `src/qlab/features/regime.py` | trend / range, high / low vol, btc strong / weak, risk on / off — признаки, известные на закрытии бара, пороги заданы заранее. Каждая проверка и каждый скан разбиваются по всем 8 режимам |
| Аномалии | `src/qlab/discovery.py`, событие `anomaly` | 10 аномалий (99-й скользящий процентиль): объём, верхние и нижние тени, импульс свечи, размах, ATR, расхождение с BTC, перекос агрессоров, удаление от VWAP, изменение OI; плюс все события библиотеки. Вопрос: «что чаще происходит после», а не «работает ли» |

## Ключевые решения

- **Discovery только на training.** Находка становится гипотезой-кандидатом, только если она значима
  после поправки Бенджамини–Хохберга **по всем проверкам скана** и одинакова по знаку на ETH и SOL.
  Кандидат регистрируется автоматически по шаблону критериев, зафиксированному в конфиге до поиска,
  и проверяется на validation — на данных, которые поиск не видел.
- **Дни — независимые кластеры.** События одного дня зависимы, режимы держатся днями. Поэтому
  p-value считается по t-распределению с числом степеней свободы по числу дней, строка учитывается
  только при ≥ 30 разных днях, контроль — 5 случайных моментов на событие.
- **Платформа проверяет сама себя.** На случайном блуждании поиск не находит ничего (0 из ~1350 проверок —
  тест `test_discovery_finds_nothing_on_random_walk`). Подмешанную закономерность находит и регистрирует
  (`test_discovery_finds_planted_effect`). Первая версия этого теста на блуждании нашла 18 «значимых»
  строк — так обнаружилась заниженная погрешность при малом числе дней, это исправлено до запуска на реальных данных.
- **Проверка причинности** распространяется на все признаки и все 24 варианта событий и аномалий, которые
  использует поиск.

## Честность: загрязнение H002

Наблюдение «после свипа цена чаще продолжает движение» сделано в отчёте nif_v1 на **всей** истории
2020–2026, включая validation и holdout. Поэтому:
- проверка H002 на validation — слабое доказательство (эти данные уже видели в агрегате);
- в YAML записано `clean_after: 2026-10-30`: holdout для H002 — только данные после регистрации;
- статус Verified для H002 невозможен раньше, чем накопится ≥ 90 дней новых данных.

Discovery этим не затронут: аномалии раньше не смотрели, holdout никто не открывал.

## Результаты первого прогона (30.10.2026, коммит f95dc22)

### H002 «Продолжение после свипа» — Rejected
[Отчёт](../reports/checks/H002/validation-20261030T091620.md). На validation (2024-01 — 2025-06):

| Монета | ТФ | Сделок | E после издержек, R | Эффект до издержек vs случайный, R (95% CI) |
|---|---|---|---|---|
| ETH | 5m | 3359 | −0.63 | +0.04 [−0.01; +0.09] |
| ETH | 15m | 1208 | −0.31 | +0.06 [−0.02; +0.14] |
| SOL | 5m | 3180 | −0.42 | +0.02 [−0.02; +0.07] |
| SOL | 15m | 1165 | −0.24 | +0.01 [−0.07; +0.09] |

Отклонена по пререгистрированным критериям: ожидание после издержек отрицательное везде, эталоны
не обыграны. Прогноз до запуска («эффект, возможно, есть, но издержки его съедят») сбылся наполовину:
**на validation нет даже эффекта до издержек** — все интервалы накрывают ноль. Наблюдение nif_v1
(0.04–0.13R) было либо особенностью 2020–2023, либо шумом. На training discovery показывает то же:
после свипа через 6 баров Δ = +0.02 / +0.03 ATR на ETH / SOL, незначимо.

### Discovery (training 2020–2023) — устойчивых находок нет
[Отчёт](../reports/discovery/20261030T091442/REPORT.md), [все 5745 строк](../reports/discovery/20261030T091442/scan.csv).

- 5745 проверок (23 типа событий и аномалий × 3 монеты × 2 ТФ × 9 срезов × 5 горизонтов),
  52 значимы после поправки BH, **0 устойчивых** (значимых на ETH и SOL с одним знаком) →
  кандидатов нет, validation для них не тратился. `news_window` выбыл: NFP за 4 года — 48 событий < 100.
- Из 52 значимых 32 — одна и та же находка в разных срезах: **пробой на BTC 5m разворачивается**
  (h = 6: Δ = −0.13 ATR, z = −6.8; на ETH 5m −0.06, z = −3.4, p(BH) = 0.055; на SOL — ноль).
  На 15m эффекта нет. Похоже на краткосрочную микроструктурную реверсию в самых ликвидных парах.
- Ещё 6 — всплеск объёма на ETH 15m → продолжение (h = 6: +0.27 ATR, z = 4.0); на SOL и BTC не подтверждается.
- **Слабые, но согласованные сигналы** (по отдельности незначимы, знак совпал на всех 6 парах монета×ТФ):
  - первый бар суток UTC (00:00) → разворот через 6 баров: Δ от −0.10 до −0.19 ATR;
  - экстремальный перекос агрессоров (taker buy/sell) → разворот через 6 баров: Δ от −0.04 до −0.10 ATR.
- **Главный вывод:** все найденные эффекты — 0.05–0.3 ATR, а издержки круга — 0.2–1.4 ATR
  (на 5m — 0.5–1.4). При рыночном входе и 1R = 1 ATR ни одна находка не может стать торгуемой.
  Это не проблема конкретных идей, а ограничение всего направления «5m/15m по рынку».

## 10 направлений по ожидаемой ценности информации (EVOI)

Ранжирование не по шансу найти прибыльную стратегию, а по тому, насколько ответ изменит дальнейшие
решения, умноженному на шанс получить ясный ответ и делённому на стоимость. Все направления, кроме
связанных с H002, проверяются на ещё не тронутых validation и holdout.

| # | Направление | Что решает ответ | Почему высокий EVOI | Стоимость |
|---|---|---|---|---|
| 1 | **Карта торгуемости: издержки × ТФ × горизонт × исполнение.** Для каждой комбинации (ТФ 5m–4h, горизонт, R в ATR, рыночный или лимитный вход с моделью неисполнения) — какой минимальный эффект в ATR переживает издержки | Продолжать ли вообще 5m/15m или перенести поиск выше | Все находки в 3–10 раз меньше издержек. Без ответа любое новое исследование рискует найти неторгуемый эффект | Низкая: данные есть, кода немного |
| 2 | **Discovery на 1h / 4h и горизонтах до 2–3 суток** | Есть ли эффекты, растущие быстрее издержек | Издержки в ATR на 1h примерно в 3–4 раза ниже, чем на 5m; движения после аномалий растут с горизонтом | Низкая: тот же сканер, другие ТФ в конфиге |
| 3 | **Перекос агрессоров → разворот (абсорбция)** — этап 1, К16 | Работает ли идея «поток поглощён» | Знак совпал на всех 6 парах; механизм ясен; данные бесплатные (aggTrades дают точную дельту) | Низкая–средняя |
| 4 | **Первый бар суток UTC (00:00) → разворот** с плацебо-часами (01:00, 23:00, 08:00) | Это эффект полуночи (дневная свеча, funding в 00:00) или любого «первого бара часа» | Совпадение знака 6/6; если переживёт плацебо — это структурный поток с понятным временем | Низкая: одна YAML-гипотеза + плацебо |
| 5 | **Объединение рынков в discovery** (метаанализ с поправкой на корреляцию ETH/SOL/BTC вместо «значимо на обеих монетах») | Не теряет ли правило «значимо и на ETH, и на SOL» реальные слабые эффекты | Правило консервативно и могло отсеять п. 3–4. Ответ меняет метод для всех будущих сканов | Низкая; риск — больше ложных находок, их отсечёт validation |
| 6 | **Разворот после пробоя на BTC/ETH 5m** (z = −6.8 / −3.4) с проверкой на артефакт цены последней сделки и с лимитным исполнением | Есть ли микроструктурная реверсия, доступная мейкеру | Самая сильная находка скана; но издержки 0.9 ATR → вопрос только о лимитном входе (связан с п. 1) | Средняя |
| 7 | **Длинная нижняя тень → движение вверх на 5m** (совпадает на ETH, SOL, BTC) | Реален ли «отказ от цены» на краткосроке | Согласованный знак на всех трёх монетах, но эффект 0.05 ATR — ценен только при положительном ответе п. 1 | Низкая |
| 8 | **Сильное удаление от VWAP → продолжение, а не возврат** (15m, знак совпал на трёх монетах) | Что верно: возврат к VWAP (К6) или моментум | Прямо проверяет популярную идею «возврата к VWAP»; если подтвердится обратное — закрывает целый класс стратегий | Низкая |
| 9 | **Опережение BTC → ETH/SOL на 1m** (этап 1, гипотеза 18) | Нужен ли BTC как фильтр времени входа | Скорее всего «нет» (лаг — секунды), но тест дешёвый и сразу закрывает направление | Низкая |
| 10 | **Ликвидации: начать бесплатную запись потока Binance сейчас**, покупку истории отложить | Нужны ли платные данные | NIF показал: даже OI без задержки не разделяет исходы — априорная ценность ликвидаций снизилась. Запись бесплатна, а история копится, пока идут п. 1–9 | Низкая сейчас, решение о покупке — позже |

Отсечено этим этапом: разворот и продолжение после свипа (H001, H002), funding spikes, всплески OI,
