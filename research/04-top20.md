# Часть 7. ТОП-20 гипотез для статистической проверки

Порядок учитывает три вещи: силу механизма, вероятность пережить издержки и цену проверки.
Лёгкость проверки: 5 — хватит бесплатных свечей и OI с Binance; 1 — нужны дорогие или
недоступные исторические данные. P(edge) — та же субъективная априорная оценка, что в части 4.

---

### 1. NIF: знак ΔOI разделяет исходы свипов (К1 + К2)
- **Описание.** Свип swing-уровня с возвратом за ≤2 бара. Если OI на свипе падает → реверсия.
  Если OI растёт, а возврата нет → продолжение.
- **Механизм.** Падение OI = закрытия позиций (принудительный поток, импакт временный).
  Рост OI = новые позиции (информированный поток, импакт постоянный).
- **Почему может давать edge.** Это единственный наблюдаемый признак, который даёт
  **противоположные** прогнозы для двух состояний одного и того же графического события.
- **Слабые стороны.** OI у Binance публикуется с шагом 5m (для 5m-ТФ это грубо); OI одной
  биржи — только часть рынка; закрывать позиции могут и информированные.
- **Лёгкость проверки:** 4.
- **Данные:** перпы ETHUSDT и SOLUSDT, свечи 1m; OI с шагом 5m (Binance metrics); BTCUSDT для контроля.
- **P(edge):** 25%. Если гипотеза падает, вместе с ней падает центральная идея исследования.

### 2. Реверсия после каскада ликвидаций (К3)
- **Описание.** Бар с объёмом ликвидаций в верхнем 1%, затем возврат за уровень, откуда начался
  каскад. Цель — 30–50% длины каскада.
- **Механизм.** Ликвидации — принудительный поток без информации. Маркетмейкеры, принявшие его,
  разгружают запас.
- **Почему может давать edge.** Самый «чистый» неинформационный поток на рынке. Плюс в моменты
  каскадов волатильность высокая, поэтому доля издержек в ATR мала.
- **Слабые стороны.** Каскад может перейти в смену режима; мало событий; исторические
  ликвидации платные; вход во время каскада — плохое исполнение.
- **Лёгкость проверки:** 2.
- **Данные:** история ликвидаций (Tardis.dev, Coinalyze, CoinGlass — платно; либо записывать
  поток Binance с сегодняшнего дня), свечи 1m, OI.
- **P(edge):** 28%.

### 3. Пара Osler на очевидных уровнях: пробой → продолжение, касание → отскок (К20)
- **Описание.** Круглые числа, PDH/PDL, equal highs. Касание без пробоя → отскок. Пробой на
  ≥0.1 ATR → короткое продолжение. Каждый уровень сравнивается с плацебо-уровнями.
- **Механизм.** Тейк-профиты стоят перед уровнем, стопы — за ним. Стопы — это рыночные
  ордера, они разгоняют цену.
- **Почему может давать edge.** У гипотезы есть эмпирика на другом рынке (FX); она **противоречит**
  SMC, поэтому это честная проверка конкурирующего объяснения.
- **Слабые стороны.** Эффект мог быть съеден алгоритмами; продолжение после пробоя короткое,
  издержки могут его съесть.
- **Лёгкость проверки:** 5.
- **Данные:** свечи 1m.
- **P(edge):** 20%.

### 4. SMT: свип монеты без подтверждения BTC (К13)
- **Описание.** ETH или SOL обновил swing high/low, BTC в то же окно — нет. Затем возврат за
  уровень → реверсия монеты.
- **Механизм.** Движение не поддержано рыночным фактором. Это идиосинкратический стоп-ран без
  новой информации; стат-арб возвращает спред монета/BTC.
- **Почему может давать edge.** Мерит «информационность» движения по самому сильному общему
  фактору крипты.
- **Слабые стороны.** Расхождение может быть началом реальной относительной силы (новость по монете).
- **Лёгкость проверки:** 5.
- **Данные:** свечи 1m ETH, SOL, BTC.
- **P(edge):** 22%.

### 5. Движение ведёт перп, а не спот (К22, B11)
- **Описание.** Резкое движение перпа при отстающем споте (Binance spot, Coinbase) и резком
  изменении базиса → реверсия перпа к споту.
- **Механизм.** Движение создано плечом, а не реальным спросом. Арбитражёры сводят базис.
- **Почему может давать edge.** Различает плечевой поток (временный) и спотовый (постоянный).
- **Слабые стороны.** Арбитраж может быть быстрее 1 бара; база спот/перп шумит из-за USDT/USD.
- **Лёгкость проверки:** 3.
- **Данные:** свечи 1m перпа и спота Binance; свечи 1m Coinbase ETH-USD и SOL-USD; курс USDT/USD.
- **P(edge):** 22%.

### 6. Абсорбция на свипе (К16)
- **Описание.** Агрессивный объём на свипе в верхних 10%, а цена прошла за уровень меньше
  0.2 ATR → реверсия.
- **Механизм.** За уровнем крупный лимитный игрок. Агрессоры остаются в убытке и выходят.
- **Почему может давать edge.** «Усилие против результата» измеримо (дельта, делённая на сдвиг цены)
  и не зависит от геометрии.
- **Слабые стороны.** Малый сдвиг бывает в толстом стакане без умысла; нужен большой объём сделок.
- **Лёгкость проверки:** 3.
- **Данные:** aggTrades перпа (дельта по сделкам), свечи 1m.
- **P(edge):** 22%.

### 7. Свип по тренду старшего ТФ (К25)
- **Описание.** Тренд 1h/4h вверх; на 5m/15m снимается локальный low с возвратом → вход по тренду.
- **Механизм.** Моментум старшего ТФ плюс реверсия младшего.
- **Почему может давать edge.** Использует один из самых устойчивых эффектов (TSMOM), а свип
  даёт короткий стоп и хороший RR.
- **Слабые стороны.** Определение тренда — степень свободы; у моментума в крипте бывают тяжёлые
  просадки на разворотах.
- **Лёгкость проверки:** 5.
- **Данные:** свечи 1m.
- **P(edge):** 18%.

### 8. Эталонная реверсия без SMC с условием на режим волатильности (К36 + К4)
- **Описание.** Доходность за 3 бара в крайних 5%, ΔOI ≤ 0, без новостей → реверсия.
  Отдельно для высокого и низкого режима волатильности.
- **Механизм.** Предоставление ликвидности; по Nagel (2012), премия выше в высокую волатильность.
- **Почему может давать edge.** Простая и прозрачная гипотеза. И она нужна в любом случае:
  все SMC-гипотезы сравниваются с ней.
- **Слабые стороны.** На ценах закрытия реверсия может быть иллюзией отскока bid/ask (Roll, 1984);
  обязательно исполнение со следующего бара.
- **Лёгкость проверки:** 5.
- **Данные:** свечи 1m, OI.
- **P(edge):** 20%.

### 9. Funding: сквиз и вымывание толпы (К9a, К9b)
- **Описание.** Funding в крайних 10%. (a) Пробой против толпы → продолжение (сквиз).
  (b) Свип по толпе, возврат, funding нормализуется → реверсия.
- **Механизм.** Перекошенная сторона вынуждена закрываться.
- **Почему может давать edge.** Позиционирование — измеримый «чужой» поток.
- **Слабые стороны.** Funding меняется медленно, в сильном тренде экстремум держится неделями.
- **Лёгкость проверки:** 4.
- **Данные:** история funding, премиальный индекс (для текущей оценки funding), свечи 1m, OI.
- **P(edge):** 15%.

### 10. Ложный выход из диапазона на открытии US (К8)
- **Описание.** Свип Asia range или диапазона до открытия US в первые 60 минут US cash open →
  реверсия внутрь диапазона.
- **Механизм.** Первый выход делают на тонком рынке; приход объёма возвращает цену к балансу.
- **Почему может давать edge.** Поток с привязкой ко времени, волатильность высокая → доля
  издержек ниже.
- **Слабые стороны.** Окна выбраны по традиции; нужен плацебо-тест сдвинутых окон; переход на
  летнее время.
- **Лёгкость проверки:** 5.
- **Данные:** свечи 1m, календарь DST.
- **P(edge):** 15%.

### 11. Ликвидность времени: ночные свипы откатывают, дневные продолжаются (К15)
- **Описание.** Свип PDH/PDL в низколиквидные часы (выходные, 20–00 UTC) против такого же свипа
  в часы US.
- **Механизм.** Ночью свип делает тонкий поток, днём — реальный объём.
- **Почему может давать edge.** Разные прогнозы для двух легко наблюдаемых состояний.
- **Слабые стороны.** Ночью ATR ниже → доля издержек выше; эффект может не пережить издержки.
- **Лёгкость проверки:** 5.
- **Данные:** свечи 1m.
- **P(edge):** 18%.

### 12. Сезонность часа недели и дрейф вокруг расчёта funding (E1, E9, B3)
- **Описание.** (a) Есть ли стабильный направленный дрейф по часам недели после нормировки
  волатильности. (b) Есть ли дрейф в последний час до 00/08/16 UTC против знака funding.
- **Механизм.** Регулярные механические потоки.
- **Почему может давать edge.** Если существует, это независимый фильтр для всех гипотез.
- **Слабые стороны.** Сезонность доходности обычно неустойчива; 168 часов недели = 168 тестов.
- **Лёгкость проверки:** 5.
- **Данные:** свечи 1m, funding.
- **P(edge):** 10%. Главная ценность — нормировка для остальных тестов.

### 13. Глубина отката после импульса; добавляет ли что-то FVG (К23, К11)
- **Описание.** После импульса ≥3 ATR за ≤3 бара: вероятность отката на ≥38% до продолжения.
  Затем то же для импульсов с FVG и без FVG при равном размере.
- **Механизм.** Возврат временной части импульса.
- **Почему может давать edge.** Откат части импульса — частный случай реверсии; тест FVG
  проверяет, есть ли у SMC-геометрии **своя** информация.
- **Слабые стороны.** Ожидаемый результат для FVG — «ничего не добавляет».
- **Лёгкость проверки:** 5.
- **Данные:** свечи 1m.
- **P(edge):** 15% для отката; 8% для FVG сверх импульса.

### 14. Сжатие → пробой: продолжение против ложного пробоя (К29 против К5)
- **Описание.** Пробой после сжатия (процентиль ATR < 20): торговать продолжение или отказ?
  Обе гипотезы тестируются вместе.
- **Механизм.** Кластеризация волатильности.
- **Почему может давать edge.** После сжатия амплитуда предсказуема; если направление пробоя
  хоть немного устойчиво, RR большой.
- **Слабые стороны.** Направление может быть 50/50; в низкую волатильность доля издержек высокая.
- **Лёгкость проверки:** 5.
- **Данные:** свечи 1m.
- **P(edge):** 14%.

### 15. Возврат к VWAP в день без тренда (К6)
- **Описание.** Отклонение от сессионного VWAP ≥ 2.5σ, без новостей, в день без тренда 1h →
  возврат к VWAP.
- **Механизм.** Давление алгоритмов исполнения временно.
- **Почему может давать edge.** VWAP — реальный ориентир исполнения для крупных заявок.
- **Слабые стороны.** Выбор якоря VWAP и определение «дня без тренда» — две степени свободы.
- **Лёгкость проверки:** 4.
- **Данные:** свечи 1m с объёмом.
- **P(edge):** 15%.

### 16. Второй свип того же уровня → пробой (К33, A20, L2)
- **Описание.** После неудачного первого свипа повторная атака в течение 48 баров → продолжение.
- **Механизм.** Лимитный продавец на уровне потрачен; повторная атака = устойчивое давление.
- **Почему может давать edge.** Ловит тех, кто торгует «двойную вершину».
- **Слабые стороны.** Противоречит гипотезе «уровень с отказами крепкий»; знак эффекта неизвестен.
- **Лёгкость проверки:** 5.
- **Данные:** свечи 1m.
- **P(edge):** 12%.

### 17. Притяжение к страйку перед экспирацией Deribit (только ETH, К21)
- **Описание.** Пятница до 08:00 UTC, цена в ±1% от страйка с максимальным OI → сжатие
  и притяжение к страйку.
- **Механизм.** Хедж дилеров в long gamma.
- **Почему может давать edge.** Механический поток, известный заранее.
- **Слабые стороны.** Знак позиций дилеров неизвестен; мало событий (52 в год); для SOL не применимо.
- **Лёгкость проверки:** 2.
- **Данные:** OI опционов Deribit по страйкам на историю (Tardis.dev); свечи 1m.
- **P(edge):** 12%.

### 18. Запаздывание альтов за BTC на 1m (К14, C15)
- **Описание.** Предсказывает ли ход BTC за последнюю минуту ход ETH/SOL за следующую.
- **Механизм.** Распространение цены от лидера.
- **Почему может давать edge.** Если лаг есть на 1m, это фильтр входа для всех гипотез.
- **Слабые стороны.** На ликвидных парах лаг, скорее всего, секунды. Ожидаемый результат — «эффекта нет».
- **Лёгкость проверки:** 4.
- **Данные:** свечи 1m или aggTrades BTC, ETH, SOL.
- **P(edge):** 8%. Дешёвый тест, который закрывает целое направление.

### 19. Затухание SMC-эффектов со временем (L7)
- **Описание.** Были ли свипы прибыльнее в 2020–2021, чем в 2023–2025.
- **Механизм.** Аномалии слабеют после популяризации (McLean–Pontiff, 2016).
- **Почему важно.** Если эффект затухает, даже положительный результат на всей истории неприменим сегодня.
- **Слабые стороны.** Режимы рынка тоже менялись; нужно учитывать волатильность.
- **Лёгкость проверки:** 5 (побочный результат тестов 1–16).
- **Данные:** те же.
- **P(edge):** — (мета-гипотеза).

### 20. Макро-релизы: спайк откатывает или продолжается (К28, E11)
- **Описание.** CPI, NFP, FOMC: знак первых 5 минут против следующих 60 минут.
- **Механизм.** Конфликт: информация (продолжение) против вакуума ликвидности (перелёт и откат).
- **Почему может давать edge.** Событие известно заранее, волатильность высокая.
- **Слабые стороны.** Мало событий (около 30 в год), исполнение в момент релиза плохое.
- **Лёгкость проверки:** 3.
- **Данные:** календарь релизов с точным временем, свечи 1m.
- **P(edge):** 10%.

## Кладбище: отброшено до теста (или отложено)

| Идея | Почему |
|---|---|
| Уровни Фибоначчи, OTE 0.705 | Нет механизма; уровни настолько плотные, что «работают» всегда. Если и тестировать, то только против плацебо (0.58, 0.66) |
| Order block / breaker как система | Нефальсифицируемо: любой исход объясним задним числом (часть 6, п. 3) |
| FVG как самостоятельный сигнал | Геометрический след скорости импульса; проверяется только как добавка к гипотезе 13 |
| Киллзоны и «Silver Bullet» по часам FX | Перенесены с другого рынка без механизма; остаются только плацебо для гипотез 10–12 |
| Power of 3 / AMD, Judas swing | Нарратив, а не правило: фаза определяется задним числом |
| Гэп CME | Касается BTC и дневного горизонта, к ETH/SOL 5m/15m отношения почти нет |
| «Тепловые карты» ликвидаций сторонних сервисов | Модель, а не факт. Вместо них — реальные ликвидации (гипотеза 2) |
| Гармонические паттерны, волны Эллиотта, ручные трендовые линии | Разметка субъективна; без алгоритма нефальсифицируемо |
| Дивергенции RSI как самостоятельный сигнал | Дублирует краткосрочную реверсию (гипотеза 8) |
| Индекс страха и жадности, соцсети на 5m | Дневные или запаздывающие данные против 5-минутных сделок |
| Long/short ratio по аккаунтам | **Отложено**: медленный показатель одной биржи; использовать как контекст к гипотезе 9 |
| Стакан L2, спуфинг, айсберги | **Отложено**: нужна дорогая история L2; вернуться, если гипотезы 1 и 6 покажут эффект |

## Протокол этапа 2 (критерии фиксируются до теста)

### Порядок проверки (от дешёвого к дорогому)
1. **Т0. Выдерживают ли издержки.** Распределение ATR в % по часам недели для 5m и 15m;
   отношение «издержки / ATR». Если на 5m в большинство часов оно выше 0.3 — на 5m тестируем
   только высоковолатильные часы или лимитное исполнение.
2. **Т1. Эталон.** Нормировка сезонности (гипотеза 12) и эталонная реверсия (гипотеза 8).
3. **Т2. Центральная гипотеза.** NIF (гипотеза 1). Её результат решает, имеет ли смысл
   остальная часть с OI.
4. **Т3.** Дешёвые гипотезы по свечам: 3, 4, 7, 10, 11, 13, 14, 16, 18.
5. **Т4.** Гипотезы с дополнительными данными: 5, 6, 9, 15, 20.
6. **Т5.** Гипотезы с платными данными: 2, 17 — только если Т2 показал эффект.

### Данные (наличие и форматы проверить)
- Публичные архивы Binance (data.binance.vision): перпы USDⓈ-M — свечи 1m, aggTrades,
  metrics (OI, long/short ratio, taker ratio с шагом 5m), funding; спот — свечи и aggTrades.
  ETHUSDT, SOLUSDT, BTCUSDT.
- Coinbase: свечи 1m ETH-USD, SOL-USD, BTC-USD.
- История ликвидаций: платные провайдеры, либо запись потока Binance с сегодняшнего дня.
- Опционы Deribit по страйкам: Tardis.dev (платно), либо запись с сегодняшнего дня.
- Календарь макро-релизов с точным временем.

### Разбивка по времени
- Обучающая выборка: 2021-01 — 2023-12. Проверочная: 2024-01 — 2025-06.
- Финальный отложенный период: 2025-07 — по сегодня. **Открывается один раз** — для гипотез,
  прошедших все остальные критерии.

### Как считаем
- Вход — только на открытии бара после сигнала. Swing-точки и FVG — только с бара, на котором
  они подтверждены.
- Исход — «тройной барьер»: +k·ATR, −k·ATR или выход по времени (12 баров), плюс сырые
  доходности на 3/6/12/24 бара. Внутри бара порядок стоп/цель — по 1m-данным.
- Издержки базово: 0.05% тейкер за сторону + 0.02% проскальзывание за сторону. Сценарий
  ×1.5 и сценарий с лимитным входом. Актуальные комиссии проверить.
- Контроль: случайные моменты с тем же часом недели и процентилем ATR. Плацебо: сдвинутые
  уровни и сдвинутые сессии.
- События одного инструмента прореживаются (не чаще одного за 12 баров). Доверительные
  интервалы — блочный бутстреп по дням.
- Регистрируется **каждая** вариация параметров. Поправка на множественные тесты —
  Benjamini–Hochberg (q = 0.05) по всем вариациям; для финалистов — Deflated Sharpe Ratio
  (Bailey–López de Prado, 2014).

### Критерии отказа (гипотеза отбрасывается, если выполнено любое)
- Ожидание после издержек ≤ 0 на проверочной выборке.
- Знак эффекта разный для ETH и SOL (без отдельного механизма для монеты).
- Эффект держится только в одном году из обучающей выборки.
- Меньше 300 независимых событий в обучающей выборке (тогда «отложено», а не «доказано»).
- Изменение параметра на ±20% меняет знак эффекта.
- Для SMC-гипотез: нет результата **сверх** эталонной реверсии (гипотеза 8) на сопоставимых событиях.
- Эффект пропадает при входе на 1 бар позже. Это скорее микроструктурный артефакт; гипотеза
  остаётся только для лимитного исполнения.

### Критерий прохождения
Значимое после поправки положительное ожидание на проверочной выборке, с тем же знаком на обеих
монетах хотя бы на одном ТФ. Стабильность минимум в 3 из 4 календарных лет. Выдерживает
издержки ×1.5. Только после этого — один прогон на отложенном периоде, и только после него —
речь о стратегии и индикаторе.
